# Employee Attendance Monitor

A simple full-stack web application for managing employees and recording daily attendance.

The project is built using **Node.js, Express.js, MongoDB, Mongoose, HTML, CSS, and JavaScript**. It provides a simple interface to add employees, record attendance, view employee records, and view attendance records.

---

## 📌 Project Overview

The **Employee Attendance Monitor** is designed to manage basic employee information and daily attendance records.

The application allows users to:

- Add employees
- View employees
- Delete employees
- Record daily attendance
- Track check-in and check-out times
- Set attendance status
- View attendance records
- Store data in MongoDB
- Access backend services through REST APIs

This project is developed as a local full-stack web application.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. To create a simple employee management system.
2. To record employee attendance digitally.
3. To store employee and attendance data in MongoDB.
4. To develop REST APIs using Express.js.
5. To connect Node.js with MongoDB using Mongoose.
6. To create a simple frontend using HTML, CSS, and JavaScript.
7. To understand how frontend, backend, and database work together.

## ✨ Features

### Employee Management

- Add a new employee
- Store Employee ID
- Store employee name
- Store employee email
- Store department
- View all employees
- Delete employees

### Attendance Management

- Select an employee
- Record attendance date
- Record check-in time
- Record check-out time
- Set attendance status
- View attendance records
- Prevent duplicate attendance for the same employee and date

### Attendance Status

The application supports:

- **Present**
- **Absent**
- **Late**
